Реализуйте консольное приложение с текстовым меню и использованием Scanner, в котором:

1. Создайте обобщённый (generic) класс Storage<T>, представляющий контейнер для хранения объектов произвольного типа T.

2. Класс Storage<T> должен содержать:
   - Приватное поле List<T> items для хранения элементов.
   - Метод void add(T item) — добавляет элемент в контейнер.
   - Метод void printAll() — выводит все элементы в консоль (по одному на строке).
   - Метод int size() — возвращает количество элементов.

3. В методе main создайте два экземпляра Storage: один для строк (Storage<String>) и один для целых чисел (Storage<Integer>).

4. Реализуйте простое текстовое меню с помощью Scanner с пунктами:
   a) Добавить строку в строковый контейнер;
   b) Добавить число в числовой контейнер;
   c) Показать содержимое строкового контейнера;
   d) Показать содержимое числового контейнера;
   e) Выйти из программы;

5. Программа должна корректно обрабатывать ввод пользователя и продолжать работу до выбора пункта "Выйти"
