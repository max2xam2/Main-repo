Задачи блока 2

1. Создайте классы "Автомобиль" и "Двигатель". Определите связь между ними через композицию. Объясните, почему это композиция, а не агрегация.
2. Реализуйте иерархию классов "Сотрудник", "Менеджер", "Разработчик" с помощью наследования. Добавьте общий метод "работать()", переопределенный в каждом подклассе.
3. Напишите класс "БанковскийСчет" с приватными полями и методами для пополнения/снятия средств. Продемонстрируйте инкапсуляцию.
4. Создайте интерфейс "Фигура" с методом "вычислитьПлощадь()". Реализуйте его в классах "Круг", "Прямоугольник", "Треугольник". Продемонстрируйте полиморфизм.
5. Разработайте классы "Книга" и "Библиотека". Используйте агрегацию для хранения списка книг в библиотеке. Объясните, почему это агрегация.
6. Создайте базовый класс "Животное" с методом "издатьЗвук()". Реализуйте подклассы "Собака", "Кошка", "Корова" и переопределите метод. Продемонстрируйте полиморфизм.
7. Реализуйте класс "Компьютер" и классы "Монитор", "Клавиатура", "СистемныйБлок". Используйте композицию. Объясните, что произойдет с компонентами при удалении компьютера.
8. Создайте класс "Пользователь" с приватными полями (имя, email). Реализуйте публичные методы доступа (геттеры/сеттеры) с валидацией. Продемонстрируйте инкапсуляцию.
9. Реализуйте иерархию "Фигура" -> "ДвумернаяФигура" и "ТрехмернаяФигура" -> "Квадрат", "Круг", "Куб", "Шар". Используйте наследование.
10. Напишите класс "Магазин" и класс "Товар". Используйте агрегацию для хранения товаров в магазине. Объясните, почему товар может существовать без магазина.
11. Создайте абстрактный класс "Фигура" с абстрактным методом "вычислитьПлощадь()". Реализуйте его в подклассах. Продемонстрируйте абстракцию и полиморфизм.
12. Разработайте класс "Отдел" и класс "Сотрудник". Сотрудник не может существовать без отдела. Реализуйте через композицию.
13. Создайте класс "Документ" и классы "ТекстовыйДокумент", "Таблица", "Презентация". Используйте наследование и переопределите метод "открыть()".
14. Реализуйте класс "Кофе" и класс "Кофемашина". Кофемашина может готовить разные виды кофе. Используйте полиморфизм.
15. Напишите класс "Команда" и класс "Игрок". Игрок может быть членом команды, но существовать независимо. Используйте агрегацию.
16. Создайте класс "Сотрудник" с приватным полем "зарплата". Реализуйте методы "повыситьЗарплату()" и "получитьЗарплату()" с ограничениями доступа.
17. Реализуйте класс "Счетчик" с приватным полем "значение". Реализуйте методы "увеличить()", "уменьшить()", "получитьЗначение()". Продемонстрируйте инкапсуляцию.
18. Создайте класс "Фабрика" и класс "Продукт". Используйте композицию. Объясните, что произойдет с продуктами при уничтожении фабрики.
19. Разработайте иерархию "ТранспортноеСредство" -> "Наземное", "Водное", "Воздушное". Используйте наследование.
20. Создайте интерфейс "ОбработчикОплаты" с методом "оплатить()". Реализуйте классы "КартаОплаты", "ЭлектронныйКошелек". Продемонстрируйте полиморфизм.
21. Напишите класс "Корзина" и класс "Товар". Товар может быть добавлен в корзину, но существовать независимо. Используйте агрегацию.
22. Создайте класс "Компьютер" с компонентами (процессор, видеокарта, память). Используйте композицию. Объясните, как управляется жизненным циклом компонентов.
23. Реализуйте класс "БазаДанных" с приватными полями подключения. Добавьте публичные методы "подключиться()", "отключиться()" с безопасной инкапсуляцией.
24. Создайте иерархию "Растение" -> "Цветок", "Дерево", "Куст". Переопределите метод "цвести()" в подклассах. Продемонстрируйте наследование и полиморфизм.
25. Разработайте класс "ПользовательскийИнтерфейс" и классы "Кнопка", "ТекстовоеПоле", "Список". Используйте агрегацию для сборки интерфейса.
