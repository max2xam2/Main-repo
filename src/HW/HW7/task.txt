Функциональные Интерфейсы: Основа Лямбд
Функциональный интерфейс — это любой интерфейс, который содержит ровно один абстрактный метод.

SAM (Single Abstract Method): Именно этот единственный абстрактный метод является "функцией", которую реализует лямбда-выражение или ссылка на метод.

Аннотация: Для явного указания и обеспечения этого правила используется аннотация @FunctionalInterface. Компилятор выдаст ошибку, если вы попытаетесь добавить второй абстрактный метод.

Цель: Функциональные интерфейсы выступают в качестве типа для лямбда-выражений, что позволяет передавать код как данные (функцию) в методы. Это ключ к функциональному стилю программирования в Java, реализованному в Streams API.

Встроенные Интерфейсы (java.util.function)
Пакет java.util.function предоставляет набор универсальных функциональных интерфейсов для самых распространенных операций. Их знание позволяет избежать написания собственных интерфейсов почти в 90% случаев.

Четыре основных категории, на которых строится большинство встроенных интерфейсов:

Function (Функция): Принимает один аргумент и возвращает результат.

Consumer (Потребитель): Принимает один аргумент и не возвращает результат (void).

Predicate (Предикат): Принимает один аргумент и возвращает логическое значение (boolean).

Supplier (Поставщик): Не принимает аргументов, но возвращает результат.

Что такое Анонимный Класс?
Анонимный класс — это класс без имени, который определяется и инстанцируется (создается) одновременно.

Одноразовое использование: Они используются, когда вам нужно создать объект, который выполняет одноразовую реализацию какого-либо интерфейса (например, Runnable) или расширение абстрактного класса (например, TimerTask).

Синтаксис: Они выглядят как конструктор родительского интерфейса или класса, за которым сразу же следует тело класса в фигурных скобках, где реализуются абстрактные методы.

Связь с Функциональными Интерфейсами: Исторически анонимные классы были основным способом реализации однометодных интерфейсов, пока в Java 8 не появились лямбда-выражения, которые теперь делают то же самое гораздо более лаконично.

Задача Собственный Функциональный Интерфейс
Нам нужен интерфейс, который принимает строку и возвращает измененную строку.

@FunctionalInterface
public interface StringProcessor {
    // Единственный абстрактный метод (SAM)
    String process(String input);

Условие Задачи
Вам нужно создать и использовать объект, который реализует StringProcessor как анонимный класс.

Цель:
Реализация должна переворачивать (реверсировать) входную строку.

Ваш первый шаг
Напишите, пожалуйста, код для создания объекта анонимного класса, который реализует StringProcessor и выполняет реверс строки в методе process.

Напомню, что реверс строки в Java часто выполняется с помощью класса StringBuilder.
